A worker no longer starts a job a second time when the queue offers it back while it is still running (a lease that ran out while beats could not get through, say): the running attempt stays and its run folder is left alone; and the queue keeps a job with the worker that beats for it again after its lease ran out, until someone else claims it. Workers also drop `fast` when triton is not installed (Windows with CUDA), with a warning, instead of crashing at the first compile.
