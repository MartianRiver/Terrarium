The skills battery keeps every checkpoint it scores (results are keyed run name and samples, so two checkpoints of one run no longer overwrite each other), counts apples apart from berries in the tree test (the world now counts apples taken off the tree), and reports the night test's survival as the starting nims still alive, the headcount with hatchlings, and the share of colonies with anyone left, instead of one average over spare places.
