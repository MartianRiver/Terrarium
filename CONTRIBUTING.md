# Contributing

Thanks for looking. I'm not taking pull requests: it's a personal project and I'd like to keep it in one head for now. Issues are welcome, though, whether something's broken or you've got an idea for the Terrikins.

For a bug, say what you were running (the viewer, training, evals, a replay), the command if there was one, which release or commit (`git log -1 --oneline`), and your OS. For the viewer, the browser too. Paste what it printed around when it went wrong; `TERRARIUM_LOG=DEBUG` gets more out of the sim, and the viewer's log panel (the backtick key, under `npm run dev`) can export its log. If it's something you saw in a replay, attach the replay file and say roughly when.

For an idea, describe what you'd like to see them do, or the moment where you wanted it. That tells me more than a feature description does.
